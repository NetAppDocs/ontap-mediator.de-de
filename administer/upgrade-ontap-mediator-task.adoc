= Upgrade von ONTAP Mediator
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Zur Aktualisierung von ONTAP Mediator auf eine neuere Version ohne Aktualisierung des Host-Betriebssystems können Sie das Installationspaket für die neue Version herunterladen und das Installationsprogramm auf dem Host ausführen, auf dem ONTAP Mediator bereits installiert ist.


NOTE: Falls Sie das Host-Betriebssystem auf eine neue Version aktualisieren und im Zuge dieses Prozesses ONTAP Mediator neu installieren oder aktualisieren müssen, finden Sie stattdessen weitere Informationen unter link:upgrade-host-os-mediator-task.html["Aktualisieren Sie das Host-Betriebssystem und ONTAP Mediator"].

.Bevor Sie beginnen
* Zu prüfen ist, ob Ihr Host die in link:../install/prepare-install.html["Vorbereitung der Installation des ONTAP Mediators"] beschriebenen Voraussetzungen erfüllt, einschließlich der Anforderungen an Host, Firewall und Betriebssystem.
* Das Installationspaket für die neue Version steht zum Herunterladen bereit. Weitere Informationen finden Sie unter link:../install/download-install-pkg-task.html["Das Installationspaket für ONTAP Mediator herunterladen"].
* NetApp empfiehlt, die Codesignatur des neuen Installationspakets zu überprüfen. Weitere Informationen finden Sie unter link:../install/verify-code-signature-task.html["Die Codesignatur des ONTAP Mediator Installationspakets überprüfen"].


.Über diese Aufgabe
Vor dem Upgrade von ONTAP Mediator sollten die folgenden Informationen geprüft werden.

* Ein Upgrade von ONTAP Mediator auf die neueste Version wird empfohlen. Ältere Versionen funktionieren weiterhin mit allen ONTAP Releases, jedoch enthalten neuere Versionen Sicherheitspatches für Drittanbieterkomponenten.
* Wenn Sie auf eine neue ONTAP Mediator-Version aktualisieren, die das SCST-Paket enthält, aktualisiert das Installationsprogramm automatisch auf die empfohlene SCST-Version, sofern keine höhere Version verfügbar ist. Anweisungen zur manuellen Installation einer höheren SCST-Version finden Sie unter link:host-maintenance-task.html["Das Host-Betriebssystem für ONTAP Mediator warten"]. Für unterstützte Versionen siehe die link:../release-notes/support-matrix.html#scst-support-matrix["SCST Support-Matrix"].


[NOTE]
====
* Wenn das Upgrade fehlschlägt, ist möglicherweise eine neuere Version von ONTAP Mediator erforderlich.
* Ab dem 15. Juni 2025 lassen sich ONTAP Mediator 1.9 und 1.8 nicht installieren oder aktualisieren, da ihre Code-Signing-Zertifikate abgelaufen sind. Falls die Aktualisierung fehlschlägt, kommt stattdessen die Patch-Version ONTAP Mediator 1.9.1 zum Einsatz.


====
* Ab ONTAP 9.19.1 und ONTAP Mediator 1.12 besteht die Möglichkeit, ONTAP Mediator mit iSCSI und HTTPS-Unterstützung oder nur mit HTTPS-Unterstützung zu installieren. Wenn ONTAP Mediator nur mit HTTPS-Unterstützung installiert wird, wird das SCST-Paket nicht installiert.
* Wenn Sie von ONTAP Mediator 1.11 oder einer früheren Version mit installiertem SCST aktualisieren und während des Upgrades die Option „Nur HTTPS“ auswählen, wird das SCST-Paket deinstalliert und die neue ONTAP Mediator Version enthält das SCST-Paket nicht.
* Wenn die Überwachung mehrerer MetroCluster IP-Konfigurationen mit ONTAP Mediator vorgesehen ist, hängt die Unterstützung vom Mediator-Typ, der ONTAP Version und dem Betriebssystem ab. Weitere Informationen finden Sie unter link:https://docs.netapp.com/us-en/ontap-metrocluster/install-ip/concept_mediator_requirements.html#mediator-multiple-mccip["ONTAP Mediator zur Überwachung mehrerer MetroCluster IP Konfigurationen verwenden"^].
* Die Installation des ONTAP Mediators mit ausschließlicher HTTPS-Unterstützung wird für die folgenden Anwendungsfälle unterstützt:
+
** Sie planen, ONTAP Mediator ausschließlich zur Überwachung Ihrer SnapMirror active sync Cluster zu verwenden.
** Es ist vorgesehen, ONTAP Mediator mit HTTPS zu konfigurieren, um eine oder mehrere MetroCluster IP-Konfigurationen zu überwachen.


* ONTAP Mediator muss mit Unterstützung für iSCSI und HTTPS im folgenden Szenario installiert werden:
+
** Sie planen, ONTAP Mediator mit iSCSI zu konfigurieren, um eine oder mehrere MetroCluster IP-Konfigurationen zu überwachen.




* Wenn Sie das Installationsprogramm für eine bestehende ONTAP Mediator Installation ausführen, erkennt es die aktuelle Version und fordert Sie auf, das Upgrade zu bestätigen:
+
`ONTAP Mediator will be upgraded from version <current-version> to <new-version>.`

+
`Do you wish to continue? Y(es)/n(o):`

* Im Rahmen des Upgrades erfasst das Installationsprogramm ein Support Bundle Ihrer Konfiguration vor dem Upgrade und migriert die Datenbank, bevor die ONTAP Mediator software aktualisiert wird.
* Für Automatisierungsanwendungen kann der  `./ontap-mediator-1.12.1/ontap-mediator-1.12.1 -y`Befehl verwendet werden, um die Installationsabfragen zu überspringen.


.Schritte
. Beim Ausführen des Installationsprogramms für die neue Version beantworten Sie die Eingabeaufforderungen nach Bedarf:
+
[source, cli]
----
./ontap-mediator-1.12.1/ontap-mediator-1.12.1
----
+
[NOTE]
====
Zum Überspringen der Signaturprüfung während des Upgrades dient der
`./ontap-mediator-1.12.1/ontap-mediator-1.12.1 --skip-code-signature-check`Befehl

====
+
Das Installationsprogramm erkennt die bestehende Installation und fordert Sie zum Upgrade auf, installiert dann die erforderlichen Pakete und migriert Ihre Konfiguration.
