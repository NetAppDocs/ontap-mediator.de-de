:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Der ordnungsgemäße Betrieb von ONTAP Mediator sollte überprüft werden.



[[verify-the-service-status]]
== Überprüfung des Service-Status

.Schritte
. Status des ONTAP Mediators:
+
.. Führen Sie den folgenden Befehl aus:
+
[source, cli]
----
systemctl status ontap_mediator

[[confirm-the-listening-ports]]
== Bestätigung der Listening-Ports

. Bestätigen Sie die vom ONTAP Mediator verwendeten Ports:
+
[source, cli]
----
netstat -anlt | grep -E '3260|31784'
----
+
[listing]
----
[root@scspr1905507001 ~]# netstat -anlt | grep -E '3260|31784'

         tcp   0   0 0.0.0.0:31784   0.0.0.0:*      LISTEN

         tcp   0   0 0.0.0.0:3260    0.0.0.0:*      LISTEN

         tcp6  0   0 :::3260         :::*           LISTEN
----
