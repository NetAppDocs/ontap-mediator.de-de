= Was ist neu in ONTAP Mediator?
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Mit jeder neuen Version von ONTAP Mediator werden neue Verbesserungen bereitgestellt.


NOTE: Informationen zur OS- und SCST-Version sind unter link:support-matrix.html["Supportmatrix"] verfügbar.

[cols="25,75"]
|===


| ONTAP Mediator Version | Verbesserungen 


 a| 
1.12.1
 a| 
* Unterstützung für RHEL:
+
** Kompatibel: 10.1 und 9.7.
** Empfohlen: 10.2, 10.0, 9.8, 9.6, 9.4 und 8.10.


* Unterstützung für Rocky Linux 10.2, 9.8 und 8.10.
* Unterstützung für Oracle Linux 10.1 und 9.8 mit sowohl rhck- als auch uek-Kerneln.
* Ab ONTAP Mediator 1.12.1 und ONTAP 9.19.1 kann eine einzelne, mit HTTPS konfigurierte ONTAP Mediator Instanz die folgenden Konfigurationen gleichzeitig überwachen:
+
** Maximal zehn Vier-Knoten- oder fünf Acht-Knoten MetroCluster IP-Konfigurationen bei Installation auf einem Host mit 8-Kern-CPU und mindestens 16GB RAM. Weitere Informationen unter link:https://docs.netapp.com/us-en/ontap-metrocluster/install-ip/concept_mediator_requirements.html#mediator-multiple-mccip["ONTAP Mediator zur Überwachung mehrerer MetroCluster IP Konfigurationen verwenden"^].
** Eine MetroCluster IP Konfiguration mit vier Knoten und eine SnapMirror active sync Peer-Beziehung, wenn sie auf einem Host mit einer 2-Kern-CPU installiert ist. Weitere Informationen unter link:https://docs.netapp.com/us-en/ontap/snapmirror-active-sync/mediator-install-task.html#ontap-mediator["Den ONTAP Mediator für SnapMirror Active Sync konfigurieren"^].


* Enthält ein neues Tool zur Reparatur einer beschädigten SCST-Installation. Nach der Installation von ONTAP Mediator befindet sich das Tool unter  `/usr/local/bin/mediator_repair_scst`. Das Tool kann nach einem Betriebssystem-Upgrade verwendet werden, wenn das aktualisierte Betriebssystem einen SCST-Patch benötigt, der im Standard-SCST-Paket nicht verfügbar ist.

1,12
 a| 
* Unterstützung für RHEL:
+
** Kompatibel: 10.1 und 9.7.
** Empfohlen: 10.2, 10.0, 9.8, 9.6, 9.4 und 8.10.


* Unterstützung für Rocky Linux 10.2, 9.8 und 8.10.
* Unterstützung für Oracle Linux 10.1 und 9.7 mit sowohl rhck- als auch uek-Kerneln.
* Ab ONTAP 9.19.1 und ONTAP Mediator 1.12 kann ein ONTAP Mediator konfiguriert werden, der HTTPS für die Kommunikation in MetroCluster IP-Konfigurationen verwendet. HTTPS bietet erhöhte Sicherheit, indem gesamte Sitzungen mit SSL/TLS verschlüsselt werden. Es besteht die Möglichkeit, ONTAP Mediator ausschließlich mit Unterstützung für HTTPS zu installieren. Das SCST-Paket wird bei Verwendung dieser Installationsmethode nicht installiert. link:../install/prepare-install.html#https-iscsi-installation["Erfahren Sie mehr über die HTTPS- und iSCSI-Installationsoptionen für ONTAP Mediator"].
